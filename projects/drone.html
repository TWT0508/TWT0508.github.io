四旋翼无人机自主穿环系统（Quadrotor Ring Traversal Challenge）

项目简介

参与香港理工大学 IEEE RAS 暑期学校项目，完成四旋翼无人机从硬件组装、飞控配置到自主飞行算法部署的全流程，实现无人机在室内动捕（Vicon）环境下按指定顺序自主穿越多个圆环并抵达终点，最终以「跟踪精度 50% + 完成时间 50%」的综合评分完成比赛。最终得分 74.1（max = 77）。

团队工作

  • 硬件组装：从零搭建四旋翼无人机，包括碳纤维机架、MicoAir743-AIO 飞控（集成 4-in-1 ESC、运行 PX4 固件）、无刷电机与桨叶、3S 580mAh LiPo 电池、Orange Pi 机载电脑、ELRS 遥控链路、MTF-02P 光流/ToF 激光测距传感器；完成电机电源线焊接、电容与 LED 灯带安装、整机走线等。
  • 系统配置与标定：使用 QGroundControl 完成加速度计/陀螺仪/水平面/遥控器/电机等标定；配置 PX4 参数（EKF2 外视觉定位、禁用 GPS/气压计/测距融合），实现基于 Vicon 动捕的室内状态估计。
  • 通信链路搭建：基于 Ubuntu 22.04 + ROS2 Humble + MAVROS + PX4 构建机载自主飞行栈；配置 MAVROS 串口波特率 921600、ROS_DOMAIN_ID 多机组隔离、ENU→NED 坐标变换，打通「Vicon → VRPN → MAVROS → PX4 EKF2」的位姿数据流。
  • 仿真验证：在 Gazebo SITL 环境启动 X500 视觉模型，联合 QGC、MAVROS、RViz2 完成 OFFBOARD 自主飞行全流程仿真（等待飞控→预流式设定点→切 OFFBOARD→解锁→起飞→航点跟踪→降落→自动上锁）。
  • 自主飞行与调参：部署 offboard 控制程序，采用 20Hz 位置设定点预流式发送 + OFFBOARD 模式切换策略；基于前瞻点（look-ahead / pure pursuit）路径跟踪算法实现按航点序列自主穿环，通过调优 lookahead_distance 参数在跟踪精度与完成时间之间取得平衡。
